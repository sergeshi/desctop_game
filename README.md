# Desktop Detective

Детективная игра в формате интерактивного персонального компьютера.

## Запуск
1. Установите Python 3.10 или новее.
2. Откройте репозиторий в PyCharm или другой Python IDE.
3. Запустите main.py.
4. Браузер откроется по адресу http://127.0.0.1:8000.
5. Для остановки прервите выполнение main.py.

Сторонние Python-пакеты не нужны.

## Возможности прототипа
- macOS-inspired оболочка с меню, Dock и перемещаемыми окнами;
- альтернативные темы Retro Linux и FreeBSD workstation;
- сообщения, телефон, почта, файловый менеджер, музыка, браузер, заметки и расследование;
- синтез телефонных реплик через SpeechSynthesis API браузера;
- три оригинальные мелодии, синтезируемые через Web Audio API;
- воспроизведение аудиофайлов, выбранных с компьютера;
- поиск по сообщениям, письмам и уликам;
- автосохранение заметок, темы, сообщений и улик в localStorage.

Голоса зависят от браузера и установленных в системе голосовых пакетов. Звук запускается после действия пользователя из-за ограничений браузеров. Выбранные локальные файлы не отправляются на сервер.

Это прототип: контент приложений демонстрационный, а полноценные сюжетные события и контакты будут добавлены следующим этапом.


## Визуальный редактор диалогов

В режиме разработки откройте вкладку **«Диалоги»**. Редактор поддерживает:

- перемещение узлов мышью по рабочему полю;
- соединение выходного порта одного узла со входом другого;
- узлы «Старт», «Реплика», «Выбор игрока», «Условие» и «Конец»;
- несколько подписанных выходов у узлов выбора;
- условия по состоянию расследования: наличие улики, изученная фотография, сохранённое вложение и прочитанное письмо;
- тестовый проход по графу с выбором ветвей;
- автоматическое сохранение структуры графа в локальном хранилище браузера.

Чтобы создать ветвление, добавьте узел **«Ветвление»**, настройте подписи выходов, затем соедините каждый выход с нужным узлом. Узел **«Условие»** автоматически выбирает ветвь «Да» или «Нет» во время тестового прохода.


## Игровой исполнитель графов

Графы теперь запускаются от реальных событий ОС, а не только из тестового окна редактора. Узел **«Старт»** задаёт событие-триггер: запуск игры, изучение фотографии, прочтение письма, отправка сообщения, принятие или отклонение звонка. Узел **«Реплика»** добавляет входящее сообщение в приложение «Сообщения». Узел **«Выбор игрока»** показывает интерактивное окно выбора и продолжает граф по выбранному выходу. Узел **«Условие»** проверяет состояние расследования и автоматически выбирает выход «Да» или «Нет». Узел **«Действие»** может отправить сообщение или письмо, инициировать звонок, добавить улику, обновить цель, открыть приложение или завершить квест. Узел **«Конец»** завершает цепочку.

В инспекторе узла «Старт» выбирается событие запуска, а в узле «Действие» — эффект. Заголовок действия используется как тема письма или название улики, текст — как содержимое. Реплики и письма по умолчанию отправляются от Алексея Морозова. Сценарий хранится в localStorage этого браузера вместе с остальным состоянием игры.

### Система состояния расследования

Вкладка **«Состояние дела»** в режиме разработки позволяет создавать и редактировать:

- переменные (числа, строки и логические значения);
- флаги сюжетных событий;
- отношения с персонажами (диапазон от −100 до 100);
- предметы инвентаря;
- историю последних изменений и список зарегистрированных улик.

Состояние хранится в отдельном объекте `investigation` внутри локального сохранения браузера. Оно сохраняется автоматически и доступно всем графам. Старые сохранения сохраняются: при первом запуске недостающая структура создаётся автоматически.

В узле **«Действие»** доступны операции `set_variable`, `add_variable`, `set_flag`, `set_relationship`, `change_relationship`, `add_item` и `remove_item`, наряду с прежними сюжетными действиями.

Узел **«Условие»** принимает логические выражения с операторами `AND`, `OR`, `NOT` (или `&&`, `||`, `!`), скобками и сравнениями `==`, `!=`, `>`, `>=`, `<`, `<=`. Доступны функции:

- `flag("found_photo")` — проверка флага;
- `item("apartment_key")` — наличие предмета;
- `evidence("photo_01")` — наличие улики;
- `rel("alex")` — значение отношения;
- `var("trust_score")` — значение переменной.

Например: `flag("found_photo") AND rel("alex") >= 50 AND item("apartment_key")`.

У вариантов узла **«Выбор игрока»** можно указать отдельное условие доступности. Варианты, условие которых не выполнено, не показываются игроку.

Система работает локально в браузере и пока не синхронизирует сохранения между устройствами. Произвольный JavaScript в условиях не выполняется — используется ограниченный интерпретатор выражений.
